یک مدل زبانی کوچک (به سبک GPT) نوشتم که روی کاراکترها کار می‌کند، تقریباً ۸۰۰ هزار پارامتر دارد و فقط به PyTorch نیاز دارد. حتی روی CPU هم آموزش می‌بیند.




روش استفاده از tiny_llm.py:

pip install torch را اجرا کنید.
یک فایل متنی به نام data.txt کنار فایل بگذارید. می‌تواند کتاب، مقاله یا چت‌های خودتان باشد. هرچه بیشتر و یک‌دست‌تر باشد، بهتر است.
برای آموزش، python tiny_llm.py train را اجرا کنید. روی CPU چند دقیقه طول می‌کشد.
برای تولید متن، python tiny_llm.py chat "شروع جمله" را اجرا کنید.

این مدل یک ترنسفورمر ۴ لایه است که کاراکتر بعدی را پیش‌بینی می‌کند، همان اصل کار GPT. چون کوچک است، فقط سبک و الگوی متن آموزشی را یاد می‌گیرد و مثل ChatGPT پاسخ‌گو نیست.

اگر سیستم ضعیفی دارید، n_layer را به ۲ و n_embd را به ۶۴ کاهش دهید. برای مدل قوی‌تر، همان مقادیر را بالا ببرید و متن بیشتری بدهید.

اگر خواستید، می‌توانم نسخه‌ای بسازم که به‌جای کاراکتر روی کلمه یا توکن کار کند، یا آن را به شکل چت‌بات درآورم.
